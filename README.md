# PIB India - Previous Day RSS Feed

An RSS 2.0 feed with every English press release published by PIB Delhi on the
previous calendar day (IST). It is rebuilt automatically every morning and
hosted on GitHub Pages.

## Subscribe

```
https://gkgangavarapu.github.io/pibindia-rss/feed.xml
```

Add it to any RSS reader. In KOReader use **News Downloader** and paste the URL.
The full text of every article is already inside the feed, so leave
**"Download full article" unchecked**. News Downloader will then build a single
text-only EPUB (no images) from the feed.

## Ready-made EPUB

The same content as one file, if you prefer not to use the feed:

```
https://gkgangavarapu.github.io/pibindia-rss/pib-news.epub
```
